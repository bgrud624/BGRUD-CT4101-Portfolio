# BGRUD-CT4101-Portfolio
Semester-long ML model portfolio for University of Galway CT4101 Machine Learning module

Python + package version numbers:
Used Python 3.14.3. Should work with >=3.13.
Install dependencies with: pip install -r requirements.txt

To run: open in any framework for executing jupyter notebooks and make sure your global python or your venv has at minimum the listed package verison numbers to ensure it runs smoothly. Execute each block of code sequentially and recieve the results.
